# Seasonal-Agriculture-Performance-Analysis

## Overview
This project analyzes 4,000 farm-level agricultural records across three seasons — Kharif, Rabi, and Zaid — to identify seasonal patterns in crop yield, production, profit, and resource usage. It is a data analytics project (no machine learning or dashboard).

## Problem Statement
Agricultural activities are influenced by seasonal variations in environmental conditions, farming practices, and resource availability. This project investigates how performance differs across seasons using descriptive statistics, visualizations, and evidence-based interpretation.

## Dataset
- File: `seasonal_agriculture_performance_dataset.csv`
- Records: 4,000
- Columns: 28 (crop, season, state, district, rainfall, soil data, yield, production, cost, revenue, profit, water usage, etc.)

## Key Findings
- Kharif shows the highest yield, production, and profit; Zaid shows an overall seasonal loss.
- Median profit is negative in Rabi and Zaid despite positive mean profit, showing most farms underperform the average.
- The Kharif > Rabi > Zaid yield ranking holds across every crop.
- Punjab and Maharashtra are the top-performing states; Andhra Pradesh is the lowest.
- Higher fertilizer usage is linked to lower profit, not higher yield.
